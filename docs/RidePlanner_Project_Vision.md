# Ride Planner - Project Vision & Roadmap

> This document captures the initial vision for the Ride Planner
> project. It is intended to evolve over time.

## Goal

Build a production-quality motorcycle ride planning platform focused on
Indian riders while using the project to learn software architecture,
full-stack development, cloud deployment, and system design.

## Primary Objectives

-   Build a portfolio-quality application.
-   Learn by designing before coding.
-   Follow professional software engineering practices.
-   Keep GitHub as the single source of truth.

## Technology Stack (Initial)

### Backend

-   ASP.NET Core Web API
-   Entity Framework Core
-   PostgreSQL
-   JWT Authentication

### Frontend

-   React + TypeScript
-   Vite

### Future Mobile

-   React Native

### Infrastructure

-   Docker
-   GitHub Actions
-   Google Cloud (later)

## Development Philosophy

-   Build in small milestones.
-   Documentation first.
-   Design before implementation.
-   One feature at a time.
-   Refactor when necessary.
-   Keep architecture simple until complexity is justified.
